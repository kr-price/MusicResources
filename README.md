# Music Resources

This is a repository of music-making software and music theory videos I've found! This was created for my friend Enji, but anyone is welcome to use it :)

## DAWs

(If you are like Enji and already have a DAW, you can skip this section!)

Before diving into digital music-making, start with downloading a DAW (Digital Audio Workstation) of your choosing. This is the main software you will use. Popular ones are:

- [Ableton Live](https://www.ableton.com/en/shop/live/?tab=buy-now) *(from my understanding, this seems to be the best for EDM)*

- [FL Studio](https://www.image-line.com/)

- [Avid Pro Tools](https://www.avid.com/pro-tools)

## VSTs

VSTs (Virtual Studio Technologies) are plugins you can add to your DAW that will generally have one of two purposes:
1. Acting as a virtual instrument (e.g., piano, guitar, drums) 
2. Providing FX such as reverb, delay, or amplification!

Here are some websites you can download VSTs from (I have done a quick verification of all these sites, but please remain cautious):

- [Free VST Hub](https://freevsthub.com/)

- [Plugins4Free](https://plugins4free.com/)

- [Plugin Boutique](https://www.pluginboutique.com/) *(mostly paid VSTs, but there seems to be heavy discounts often)*
